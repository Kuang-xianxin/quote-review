# 验证记录与局限

**简体中文** · [English](VALIDATION.md) · [项目首页](../README.zh-CN.md)

参考环境：Windows、Node.js 22.23.1、TypeScript 5.9.3。这里记录实现验证，不是生产服务性能基准。

2026-09-11 的双语更新通过 35 项自动测试和 14 项确定性案例断言。还对中英文首页分别执行了 React 静态渲染检查。类型检查、lint 和生产构建的最终结果参见 [GitHub Actions](https://github.com/Kuang-xianxin/incident-weave/actions)。这些检查不等于浏览器交互或 GPU 验收。

## 复现

```sh
npm ci
npm test
npm run typecheck
npm run lint
npm run eval
npm run build
npm run investigate -- samples/retry-storm.log samples/retry-storm.md --lang zh-CN --json
```

测试覆盖导入、脱敏、来源身份、日志与手册区分、词法检索、未知证据、引用拒绝、事件关联、摘要稳定性、输入上限、CLI 参数和 Worker 生命周期。新增双语验证覆盖语言优先级、中文案例诊断、报告本地化不改写证据和模型内容、模型语言提示不改变引用约束、CLI 语言参数不被误当文件。

Worker 生命周期测试使用可控替身，验证完成、取消、格式错误和 Worker 失败时 Promise 正确结束并终止所属任务。**它们不测量 WebGPU 执行、模型质量、GPU 显存回收或浏览器下载缓存。**

模型适配器已编译，模型标识来自所装运行时的目录。真实模型下载与推理、中英文模型输出质量、跨浏览器 GPU 行为尚未验证，不能宣称已通过模型效果基准。不支持的设备会提示错误并保留确定性分析。

WebMCP 有适配器级结构和状态转换检查，尚未在支持该实验 API 的浏览器中验证注册。普通使用不依赖 WebMCP。

## 影响使用的局限

- 合成案例不能证明真实事故的根因准确率。
- 引用匹配不能证明引文与结论的语义关系或真实性。
- BM25 是词法检索，可能漏掉同义改写。
- 来源类型由用户选择，应用不能认证日志来源。
- 提示注入样式检测和凭证脱敏依赖有限规则。
- 模型上下文按行数和字符数限制，特殊分词仍可能超过模型 token 上限，此时会失败并保留报告。
- 小模型可能没有可用假设，或未遵循所选语言。已有输出保留实际生成语言，重新运行才会请求新语言。
- 输入容量适合小范围事故排查，不适合批量导入全量遥测数据。

后续模型评估应记录模型与运行时版本、硬件、提示词、输入、生成配置、格式错误率、引用拒绝率，以及人工标注的支持度和因果判断。不要把这些指标合并成缺乏口径的“准确率”。
