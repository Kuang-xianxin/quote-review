# 验证范围

本次验证覆盖真实本地 API、独立解析进程、CPU 模型和公开部署。完整合成输入、预期字段、实际模型输出、耗时和错误见 `validation/model-regression.json`；较小基线模型的失败记录保留在 `validation/baseline-qwen2.5-1.5b.json`。

样例数量有限，涵盖中英文报价、不同商品、独立起订量单位、不明确币种、恶意指令、双行 CSV/XLSX 与文字 PDF。前两个样例参与过提示调整，不能称为保留测试集。未使用真实供应商数据，也没有真实用户采用或生产准确率结论。

API 自动测试使用真实临时 SQLite 与文件存储，只有模型回传是替身数据；验证会话隔离、跨站拒绝、并发上传限额与去重、租约领取、旧结果拒绝、并发人工核对与审计、删除清理、十进制换算和 CSV 公式处理。解析测试覆盖位置、表格、公式、扫描件、超限输入与邮件正文。

模型实测使用 i5-12400、约 25 GB 内存、4 个 CPU 线程，固定 Qwen3-4B-Q4_K_M 权重，不调用远端推理 API。耗时不含下载和模型启动，仅包含每例解析与提取。

未进行浏览器视觉或点击验收；编译和 HTTP 检查不能证明所有交互。公开接口验证在部署后单独记录。扫描 PDF、复杂表格布局、按公斤或米计价等暂不属于已验证范围。
