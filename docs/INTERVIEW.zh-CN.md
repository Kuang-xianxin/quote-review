# 用这个项目准备 AI 应用工程师面试

**简体中文** · [English](INTERVIEW.en.md) · [项目首页](../README.zh-CN.md)

## 一分钟介绍

“我做了一个免费开源的 AI 应用故障调查工作台。输入运行日志和操作手册，它会先用确定性规则、检索和事件关联建立证据，再让用户选择是否在自己的浏览器运行开源小模型生成调查假设。每个模型引用必须匹配真实原文，取消请求会终止本次任务拥有的 Worker。项目不依赖付费 API，可以静态部署，也提供命令行入口和可复现评估。”

这段介绍描述的是项目能力。代码由 AI 协助实现；只有自己理解、运行并验证后，才能在面试里说清楚个人掌握程度。不要虚构真实客户、生产流量、团队规模、模型准确率或独立完成的测试。

## 面试现场的五分钟演示

1. 打开工作台，选 **没有停下的任务 / The task that stayed**。说明所有演示日志是合成数据。
2. 点击 **开始排查 / Investigate**，展示同一个 trace 在取消请求后仍有心跳；点击引用，指出时间戳、运行编号和原文行号。
3. 把后续心跳的 trace 改成其他编号，重新运行。说明为什么系统不应再作出“同一任务仍在运行”的观察。
4. 打开 **分析过程 / Run trace**，区分检索、规则分析、引用验证各阶段。打开 **本地 AI / Local AI**，解释它是可选的本地生成式步骤；没有实际加载时不能把规则结果叫模型输出。
5. 导出 Markdown 和 JSON，说明前者可用于事件工单，后者保留证据摘要、引用和 SHA-256 指纹。

如果机器不支持 WebGPU，直接说明硬件限制，继续演示确定性分析和代码。不要假装运行过本地模型。

## 重点问题与回答思路

**为什么不直接把整份日志塞给模型？**

上下文预算、隐私、噪声和来源可追溯性都会受影响。先限制输入规模、保留行号、脱敏、区分日志和手册，再检索相关证据。当前检索是 BM25，优点是零模型下载、可复现；缺点是不理解同义改写。不能把它说成向量检索或混合检索。

**如何防止模型编造引用？**

模型只看到被选中的 evidence ID 和文本。返回结果必须满足数量/长度边界，引用 ID 必须在所给上下文中，quote 必须是该原文的精确子串，检测到指令式内容的证据不能引用。错误输出不会覆盖已有报告。

**引用存在是不是说明结论正确？**

不是。这只验证“这段话确实存在”。模型可能用无关的真引文支持错误推论，所以界面始终标为未确认假设。测试专门保留一个“真引用、错因果”的案例来说明边界。后续要增加语义支持度评估，必须用标注数据实际测量。

**取消为什么不只改一个 loading 状态？**

界面停止显示不代表计算停止。本项目一个模型运行对应一个专用 Worker，取消时终止它，同时拒绝对应 Promise、清理计时器、保留已完成的确定性报告。还要处理取消后晚到的完成消息。测试用可控 Worker 替身验证生命周期，这不等于真实 GPU 推理测试。

**怎么评估？**

先做行为可验证的合成场景和反例：重试风暴、空上下文、取消后的任务活动；再验证未知引用、篡改引用、提示注入样式、输入超限、CLI 参数和取消竞态。`npm run eval` 的结果是确定性行为检查，不是模型准确率，更不是线上 SLA。

**为什么做静态部署？**

用户要求免费开源且无额外 API 开销。计算和可选模型在访问者设备执行，不需要托管推理服务。代价是浏览器能力、内存、首次下载量和小模型质量限制。若未来做企业服务，要单独设计身份隔离、日志接入、权限和保留策略；本版没有这些能力。

**双语为什么不能直接翻译整份报告？**

证据原文、物理行号、引用编号、用户问题和摘要指纹必须保持原样。只有应用自己生成的说明文案可以切换语言。模型已有结论保留实际生成语言，重新运行才请求另一种语言；翻译不能冒充新推理，也不能改变证据。

## 必须亲手做的练习

- 跑 `npm ci`、`npm test`、`npm run eval` 和 CLI 示例。
- 在 `core/engine.ts` 找出来源类型过滤、BM25、trace 关联、引用验证与摘要指纹。
- 为一种新故障先写一个失败测试，再修改规则；同时加一个不应命中的反例。
- 解释“请求者取消”和“底层任务必须停止”为什么取决于所有权，不能一律传播或屏蔽。
- 在支持 WebGPU 的机器真实跑一次本地模型，记录模型、硬件、加载时间、输出、被拒绝的引用；不要用其他机器或模拟测试的结果冒充自己的验证。

## 简历表述边界

可以写：“构建本地运行的 AI 故障调查工具，实现证据检索、跨日志关联、结构化引用验证、可取消模型任务及可复现评估，并提供公开演示与 CLI。”

不要写：“生产级自治运维平台”“根因准确率 99%”“零幻觉”“大规模分布式 Agent 系统”。本版没有支撑这些表述的数据和实现。
